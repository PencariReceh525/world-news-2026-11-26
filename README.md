One image that sums up the world news of Thursday 26 November 2026: US
tariffs on 14 partners, the Cairo fuel-tanker fire, Houthi strikes on Saudi
Arabia, Ukraine's strike on a Russian airbase, the West Java mine rescue and
the first Pakistani astronaut aboard Tiangong, plus a footer strip with the
day's other big stories. `main.py` writes the image to `/output/entry.png`;
`generate_image.py` is the drawing program that produced it, and
`NEWS_SOURCES.md` lists the same-day reporting each story was checked
against.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
