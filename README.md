One illustrated front page that sums up the world news of Thursday
26 November 2026 — 37 stories in all: a drawn lead scene of the storm that
postponed Macy's 100th Thanksgiving parade, a world map with numbered pins,
drawn scenes for US tariffs, the Cairo tanker fire, Ukraine's airbase
strike, the Ras Tanura refinery attack, the first Pakistani astronaut
aboard Tiangong and the Gukesh–Sindarov chess title match, plus 30 briefs.
`main.py` writes the image to `/output/entry.png`; `generate_image_v2.py`
is the drawing program that produced it, and `NEWS_SOURCES.md` lists the
same-day reporting each story was checked against.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
